## 1. Purpose

This Contact page explains how customers, users, partners, community members, security researchers, and other interested parties can contact APIForge.

APIForge is a platform for designing, managing, validating, and maintaining OpenAPI-based API specifications. Because APIForge may be used for production API design, internal API governance, partner integrations, and collaborative technical documentation, different types of inquiries should be routed to the appropriate contact channel.

Using the right contact channel helps APIForge respond more efficiently and ensures that security, legal, billing, support, and product-related messages are handled by the correct team or process.
