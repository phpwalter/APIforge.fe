## 1. Introduction

This Privacy Policy explains how **APIForge** collects, uses, stores, shares, and protects information when users access or use APIForge websites, applications, APIs, services, documentation, integrations, and related features.

APIForge is a platform for designing, managing, editing, validating, and exporting OpenAPI documents and related API design artifacts. Because APIForge may process API definitions, project metadata, integration data, account information, and user preferences, this policy describes how that information is handled.

This Privacy Policy applies to:

- Visitors to the APIForge website.
- Users who create or access an APIForge account.
- Organizations, teams, and workspaces using APIForge.
- Users who upload, create, import, export, or manage OpenAPI documents through APIForge.
- Users who connect APIForge to third-party services such as GitHub, GitLab, Bitbucket, Slack, Google, Microsoft, Atlassian, or other supported integrations.

This Privacy Policy does **not** apply to third-party websites, services, repositories, APIs, or platforms that APIForge does not control.

## 2. Summary

APIForge collects information needed to operate the service, secure user accounts, support collaboration, process billing, improve product quality, and provide integrations.

In practical terms, APIForge may process:

## 7. Vendor Extensions and Internal Metadata

OpenAPI allows custom vendor extension fields prefixed with `x-`. APIForge may use `x-apiforge` fields to preserve editor state, workflow metadata, preferences, notes, and other APIForge-specific information.

APIForge may offer different export modes, such as:

- **Full APIForge Export**, which includes `x-apiforge` metadata for round-tripping back into APIForge.
- **Clean OpenAPI Export**, which removes APIForge-specific metadata for external sharing, partner delivery, documentation publishing, or SDK generation.

Customers are responsible for selecting the appropriate export mode and reviewing files before external distribution.
